# ComfyUI-3DGS-Node

3D Gaussian Splatting (3DGS) シーンを ComfyUI 上で読み込み・編集し、複数カメラのアングルを画像として書き出すカスタムノードです。

- **3DGS ビューア**: `.ply` (INRIA 形式) / `.splat` / `.sog` (PlayCanvas SOG v2) をノード内ビューポートに表示。マウスとキーボードで自由に移動・回転・ズーム。
- **メッシュ配置**: `.glb` / `.gltf` / `.obj` / `.stl` / `.fbx` を追加読み込みし、ギズモまたは数値入力で 3DGS シーン内に配置(移動・回転・拡大縮小)。複数メッシュ対応。
- **マルチカメラ**: カメラを何個でも追加でき、カメラごとに FOV(視野角)とアスペクト比を設定。
- **画像書き出し**: 実行すると各カメラアングルを指定解像度でレンダリングし、IMAGE(リスト)として出力。

## インストール

新しいPCでの手順は **[Windows用](INSTALL.md)** / **[macOS用](INSTALL_MACOS.md)** を参照してください。

このフォルダごと ComfyUI の `custom_nodes` に置き、Windowsでは `install_windows.bat`、macOSでは `install_macos.command` を実行してから再起動してください。

```
ComfyUI/custom_nodes/3DGS_node/
```

必要なPythonライブラリは numpy / Pillow / torch / aiohttp です。通常はComfyUIに導入済みで、セットアップは不足分をインストールします。three.js は `web/vendor` に同梱済みです。

## 使い方

1. `.ply` / `.splat` / `.sog` / メッシュファイルを `ComfyUI/input` に置く(またはノードの「📤 ファイルをアップロード」ボタンを使用)。
2. ノードを接続:

```
[Load 3DGS Model] ──gs_model──▶ [3DGS Scene Editor & Render] ──images──▶ [Save Image など]
[Load Mesh Model] ──mesh─────────▲
```

複数メッシュは `Load Mesh Model` の `append_to` に別の `Load Mesh Model` を数珠つなぎにします。

3. ビューポートでシーンを編集(下記操作方法)。
4. `width` で出力横幅を指定して実行。**高さはカメラごとのアスペクト比から自動計算**され、カメラの数だけ画像がリストで出力されます。

### ビューポート操作

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 視点回転 — **未選択時は視点(カメラ位置)中心、メッシュ選択中はオブジェクト中心** |
| 右ドラッグ | パン |
| ホイール | ズーム |
| W / A / S / D | 前後左右移動 |
| Q / E | 下降 / 上昇 |
| Shift | 移動 4 倍速 |
| Z / X | 移動速度を下げる / 上げる（1回で約0.71倍 / 1.41倍、長押し可） |
| 矢印キー | 視点の回転(首振り) |
| メッシュをクリック／一覧から選択 | 選択してギズモと黄色い範囲枠を表示(空クリックで解除) |
| F／「選択へ移動」 | 選択メッシュ全体が見える位置へ移動 |
| 1 / 2 / 3 | ギズモを移動 / 回転 / 拡縮に切替 |
| Ctrl+D | 選択メッシュを複製 |
| Delete | 選択メッシュをビューから削除(「👁全表示」で非表示分を復元) |
| Esc | メッシュ選択解除 |

※ キー操作はビューポートをクリックしてフォーカスしてから。
※ メッシュをギズモや数値入力で動かしてもカメラ視点は追従しません。

メッシュ選択中はツールバー下に**数値入力パネル**(位置 XYZ / 回転° XYZ / 倍率 XYZ)が表示され、ギズモと双方向に同期します。「**均等**」チェックで拡大縮小が等倍(XYZ 連動)になります。「⧉複製」「✕削除」ボタンも同パネルにあります。

**速度スライダー**で WASD/QE の移動速度を **0.001〜10 倍**に調整できます。新規シーンの初期値は0.1倍です。**Zキーで減速・Xキーで加速**もでき、スライダー表示と保存値に反映されます。メッシュの操作モードは**1:移動 / 2:回転 / 3:拡縮**で切り替えます。キー操作はビューポートにフォーカスしているときに有効です。既存ワークフローの速度は維持するので、速い場合はスライダーを左へ動かしてください。

**メッシュ一覧**から画面外のメッシュも選択できます。「**選択へ移動[F]**」で全体が見える位置へ視点を移します。この操作は現在のカメラ設定に反映されます。黄色い範囲枠は3DGSの奥でも見え、画像出力には含まれません。非表示メッシュを一覧から選ぶと再表示されます。

新しく配置するメッシュは、ファイルの原点ではなく**形状の中心**を3DGSの中心に合わせます。読み込み時は新規追加分を選択しますが、カメラは自動移動しません。保存済みの配置は維持します。

**☀太陽光**: 方位・高度・強さ・色・環境光をスライダーで調整できます(メッシュの陰影に反映。3DGS 自体は焼き込み済みのため影響しません)。

**表示チェックボックス**でビューポート描画を停止できます(重いシーンでの軽量化用。ノード実行時の画像出力には影響しません)。

### カメラ

- **＋追加**: 現在の視点を新しいカメラとして追加。
- ドロップダウンでカメラを切り替えると、その視点にジャンプ。**視点を動かすと選択中のカメラに即時反映**されます。
- **レンズmm**: カメラの焦点距離(35mm フルサイズ換算、4〜1200mm)。**比率**: 出力アスペクト比(プリセット or 任意値)。ビューポート内の白枠が出力範囲を示します。
- カメラ設定はワークフローに保存されます。

### その他

- **上下反転**: COLMAP 系(Y 軸下向き)のシーンを Y 上向きに表示するトグル(デフォルト ON)。
- **背景色** / **グリッド** 表示切替。

## OBJのテクスチャ読み込み

OBJの形状に加え、`mtllib` で指定されたMTLと、MTLから参照される画像を読み込みます。

- アップロードでは **OBJ 1個・MTL・テクスチャ画像を同時選択**してください。ファイル名を保持した専用フォルダに保存します。繰り返しアップロードしても以前の組と混ざりません。
- 手動配置では `ComfyUI/input/Test2/` などに関連ファイルをまとめて置き、`Test2/Test2.obj` を選択します。サブフォルダを参照するモデルは、元のフォルダ構成を保って手動配置してください。
- 例：`Test2.obj`、`Test2.mtl`、`tex_u1_v1_diffuse.jpg`、`tex_u1_v1_normal.jpg` の4ファイル。
- 拡散色・ノーマル・バンプ等のMTL材質を利用し、画像読み込み完了後に描画します。参照ファイルが欠けている場合はエラーにファイル名を表示します。
- RealityCapture等が `map_Bump` に指定した画像は、名前に `_normal` 等の区切られた `normal` があればノーマルマップとして扱います。それ以外の `map_Bump` は通常のバンプマップです。明示する場合はMTLの `norm` を使用できます。
- 一括アップロードの画像形式：JPG / JPEG / PNG / WebP / BMP。絶対パス・外部URL参照には対応しません。

## 注意事項・制限

- **レンダリングはブラウザ側 (WebGL) で行われます。実行時はこのワークフローを開いた ComfyUI のブラウザタブを開いたままにしてください**(ビューポートと完全に一致した WYSIWYG 出力になります)。タブが無い場合は `timeout_sec` 経過後にエラーになります。
- `.ply` / `.sog` は球面調和 (SH) の DC 成分のみ使用します(視点依存の色変化は近似されません)。
- `.sog` は PlayCanvas SOG **version 2**(単一 ZIP バンドル形式)に対応しています。
- `.gltf` の外部ファイル参照(別ファイルの .bin / テクスチャ)は非対応です。`.glb` を推奨します。
- `.fbx` はテクスチャを内包した単一ファイルを推奨します(外部テクスチャファイルの解決は行いません)。
- 出力画像はカメラごとにアスペクト比が異なる場合、サイズの異なる画像のリストとして出力されます(バッチではなくリスト)。

## 実行時のモデルとタブ（0.1.1）

- 描画要求は実行元のタブにのみ送信します。そのタブでワークフローを開いたままにしてください。
- キューに登録されたモデルのパスとシーン設定で描画します。実行後のファイル選択変更は、そのキューの描画対象に影響しません。
- 同名ファイルの上書きを反映するため、ノードが実際に実行される際はモデルを再取得します。大きなモデルでは実行時間が増えるため `timeout_sec` を調整してください。ファイル内容自体をキュー投入時に複製する機能ではなく、実行時のファイル内容を使用します。
- 読み込み失敗は再試行でき、メッシュ読み込み失敗も実行エラーとして通知します。

## 開発時の回帰テスト

`python -m unittest discover -s tests -p "test_*.py"` と `node --test tests/render.test.cjs tests/navigation.test.cjs tests/obj.test.cjs` で実行します。テストはComfyUI・WebGLを模擬した制御フロー検証で、実ブラウザの描画品質は別途確認してください。Node.jsはこのテスト用であり、ノードの利用には不要です。
